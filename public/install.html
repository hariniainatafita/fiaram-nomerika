Installer FIARAM NOMERIKA

Guide pour Android — dernière mise à jour : 7 novembre 2026

Télécharger la dernière version (1.19) :

Télécharger l'APK Ouvrir la version web

Important : n'envoyez pas le fichier APK par WhatsApp ou Facebook. Ces applications bloquent ou abîment souvent les APK. Partagez plutôt ce lien :

https://fiaram-nomerika.pages.dev/install

1. Installation normale

  1. Ouvrez le lien ci-dessus dans Chrome (ou le navigateur du téléphone).
  2. Appuyez sur Télécharger l'APK.
  3. Quand le téléphone demande l'autorisation, choisissez Paramètres puis activez Autoriser depuis cette source (Chrome, Fichiers ou le gestionnaire de téléchargement).
  4. Revenez en arrière et appuyez sur Installer.
  5. Si Play Protect affiche « Application non sécurisée » : Plus de détails → Installer quand même.

2. Erreurs fréquentes

MessageCause probableSolution
« Application non installée » / « App not installed » Une ancienne version avec une autre signature est déjà installée, ou l'espace est insuffisant. Désinstaller l'ancienne application FIARAM, redémarrer le téléphone, puis réinstaller la 1.19. Libérer de l'espace si besoin.
« Bloqué par Play Protect » / « Unsafe app blocked » APK installé hors Play Store. Appuyer sur « Plus de détails » puis « Installer quand même ». Ne pas désactiver Play Protect en permanence.
« Installation bloquée » / « Restricted settings » Réglages de sécurité du fabricant. Autoriser « Installer des applications inconnues » pour Chrome/Fichiers, puis désactiver le blocage du fabricant (voir section 3).
« Fichier APK invalide » / « Parse error » Fichier incomplet ou renommé (souvent via WhatsApp). Retélécharger directement depuis le lien GitHub, sans passer par WhatsApp/Facebook.
« Version incompatible » Android inférieur à 6.0, ou fichier corrompu. Vérifier la version Android (Paramètres → À propos). Android 6.0 minimum.
« Application non compatible avec votre téléphone » APK incomplet ou restriction du fabricant. Réessayer avec la 1.19 depuis le lien officiel, puis suivre la section 3.

3. Réglages par marque

Samsung

  • Paramètres → Sécurité et confidentialité → Auto Blocker → désactiver temporairement.
  • Paramètres → Applications → Chrome/Fichiers → Installer des applications inconnues → Autoriser.
  • Play Protect → Plus de détails → Installer quand même.

Xiaomi / Redmi / POCO (MIUI / HyperOS)

  • Paramètres → Confidentialité → Autorisations spéciales → Installer des applications inconnues → autoriser Chrome/Fichiers.
  • Sécurité → Analyse de sécurité → désactiver l'analyse automatique pendant l'installation.
  • Paramètres → À propos → tapoter 7 fois sur « Version MIUI » si l'option « Optimisation MIUI » doit être désactivée.

Oppo / Realme / OnePlus (ColorOS / OxygenOS)

  • Paramètres → Sécurité → Installation d'applications inconnues → autoriser Chrome/Fichiers.
  • Désactiver temporairement « Protection des paiements » / « Analyse des applications ».
  • Si « Mode Pur » est activé, le désactiver.

Vivo / iQOO

  • Paramètres → Sécurité → Sources inconnues → autoriser.
  • Désactiver temporairement l'analyse de sécurité de l'iManager.

Tecno / Infinix / Itel (HiOS / XOS)

  • Paramètres → Sécurité → Installation depuis des sources inconnues → autoriser.
  • Désactiver l'analyse automatique de Phone Master / Security Center.

Huawei / Honor

  • Paramètres → Sécurité → Installer des applications inconnues → autoriser.
  • Désactiver « Mode Pur » s'il est activé.

Google Pixel / Android standard

  • Paramètres → Applications → Accès spéciaux → Installer des applications inconnues → autoriser Chrome/Fichiers.
  • Play Protect → Plus de détails → Installer quand même.

4. Si rien ne marche

  • Désinstaller complètement l'ancienne application FIARAM, redémarrer, puis réinstaller la 1.19.
  • Vérifier la date et l'heure du téléphone (réglage automatique).
  • Vérifier l'espace libre (au moins 100 Mo).
  • Essayer un autre navigateur (Chrome) ou télécharger sur un ordinateur puis copier l'APK par câble USB.
  • Utiliser la version web : https://fiaram-nomerika.pages.dev → menu Chrome → « Installer l'application » ou « Ajouter à l'écran d'accueil ».

Pour nous aider à corriger : envoyez une capture d'écran du message d'erreur, la marque et le modèle du téléphone, la version d'Android, et précisez si une ancienne version de FIARAM était déjà installée.
